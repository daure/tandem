## Scratch workspace

Use this folder for notes, research, and small local experiments. Keep work inside the workspace.
Start a `notes.md` file with the objective, findings, and next steps; distinguish verified facts
from assumptions. Read existing notes before changing them and preserve user edits.

Before handing over, check that referenced local files exist and that any commands you documented
have been verified. Ask before installing dependencies, initializing Git, or using external services.
